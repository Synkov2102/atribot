# Бот-капча для Telegram

Когда в группу входит новый участник, бот запрещает ему писать и присылает в чат
простой пример (`23 + 7`, `6 × 8`) с вариантами ответа на кнопках.

- Выбрал правильный — бот возвращает права и удаляет сообщение с примером.
- Ошибся или не успел — бот удаляет его из чата на несколько минут,
  вместе с примером и служебными сообщениями о входе и выходе.
- Нажатия других участников не засчитываются.
- Если админ раньше ограничил человека, после проверки ограничение сохраняется.

Незавершённые проверки сохраняются в `data/pending.json`, поэтому перезапуск бота их не теряет.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. `cp .env.example .env` и впишите токен в `BOT_TOKEN`.
3. `npm install`
4. `npm start`

Тесты: `npm test`.

## Деплой через Docker

На сервере с Docker:

1. Скопируйте проект (`git clone` или `scp`) и создайте `.env` с токеном.
2. `docker compose up -d --build`

Логи: `docker compose logs -f`. Обновление: `git pull && docker compose up -d --build`.

Незавершённые проверки хранятся в томе `bot-data` и переживают пересборку контейнера.
Одновременно может работать только одна копия бота с этим токеном — перед запуском
на сервере остановите локальную.

## Подключение к группе

Добавьте бота в группу и сделайте админом с правами **«Блокировка пользователей»**
и **«Удаление сообщений»**. Бот работает только в супергруппах: обычная группа
обычно сама становится супергруппой, когда боту выдают права админа.

## Настройки (`.env`)

Неправильное значение — ошибка при запуске с объяснением, что не так.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота |
| `CAPTCHA_TIMEOUT_SEC` | `120` | Время на ответ, 10–3600 сек. |
| `CAPTCHA_MAX_ATTEMPTS` | `1` | Количество попыток, меньше числа вариантов |
| `CAPTCHA_OPTIONS` | `8` | Количество вариантов ответа, 2–12 |
| `KICK_BAN_SEC` | `300` | На сколько не пускать обратно после провала, от 31 сек. (меньше Telegram считает вечным баном) |

С настройками по умолчанию бот, который жмёт случайную кнопку, проходит проверку в 1 случае из 8.

## Устройство

- `src/index.js` — обработчики Telegram
- `src/checks.js` — незавершённые проверки
- `src/captcha.js` — генерация примера и вариантов
- `src/config.js` — чтение и проверка настроек
- `src/store.js` — сохранение проверок на диск
- `src/ttl-map.js` — временное хранилище для служебных сообщений
